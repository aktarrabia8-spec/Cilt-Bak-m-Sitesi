# 🌐 Web Geliştirme Projelerim

Bu depoda HTML, CSS ve JavaScript kullanarak geliştirdiğim web projeleri ve uyguladığım arayüz tasarımları yer almaktadır.

Projelerimi geliştirirken web tasarımının temel yapılarını, kullanıcı etkileşimlerini, dinamik içerik oluşturmayı ve CSS ile görsel düzenlemeyi öğrenmeye yönelik çalışmalar yaptım.

## 📌 1. Coming Soon – Web Sitesi Bakım Sayfası

HTML, CSS ve JavaScript kullanılarak geliştirilen, web sitesinin bakımda olduğunu ziyaretçilere bildiren bir web sayfasıdır.

**Özellikleri:**
- Modern ve sade arayüz tasarımı
- Gün, saat, dakika ve saniye cinsinden geri sayım
- Belirlenen süre tamamlandığında otomatik yönlendirme
- İletişim butonu ile bilgilendirme mesajı
- CSS ile ortalanmış içerik ve özel tasarım
- Hover efektleri, gölgeler ve renk geçişleri

**Kullanılan Teknolojiler:** HTML5, CSS3, JavaScript

## 🌸 2. Cilt Bakım Rehberi – Analiz ve Sağlık

HTML, CSS ve JavaScript kullanılarak geliştirilen interaktif bir cilt bakım rehberidir.

Kullanıcıların cilt tiplerini seçerek uygun bakım önerilerini ve ürün tavsiyelerini görüntüleyebilmelerini sağlar.

**Özellikleri:**
- Yağlı, kuru, karma ve hassas cilt seçenekleri
- Cilt tipine göre dinamik bakım önerileri
- Ürün ve popüler marka tavsiyeleri
- Hızlı rehber butonları
- Kaydırma hareketiyle animasyonlu bilgi kartları
- Sosyal medya ve iletişim bağlantıları
- Kullanıcı etkileşimine dayalı dinamik içerik

**Kullanılan Teknolojiler:** HTML5, CSS3, JavaScript

## 💻 Öğrendiklerim ve Uyguladığım Teknolojiler

Bu projeler sayesinde aşağıdaki konularda pratik yapma fırsatı buldum:

**HTML5**
- Sayfa yapısı oluşturma
- Div, button, section ve footer kullanımı
- ID ve class tanımlama
- Harici dosya bağlantıları

**CSS3**
- Flexbox ile hizalama
- Renk geçişleri ve arka plan tasarımı
- Border, border-radius ve box-shadow
- Hover, transition ve transform
- İçerik düzenleme ve görsel tasarım

**JavaScript**
- Değişkenler ve fonksiyonlar
- DOM işlemleri
- Olay dinleyicileri (Event Listener)
- Döngüler ve nesneler
- Tarih ve zaman işlemleri
- Geri sayım uygulaması
- Dinamik HTML içerikleri oluşturma
- setInterval(), setTimeout() ve alert()

## 🎯 Projelerin Amacı

Bu çalışmaların temel amacı web geliştirme alanındaki bilgilerimi pekiştirmek, HTML, CSS ve JavaScript becerilerimi geliştirmek ve öğrendiklerimi uygulamalı projelere dönüştürmektir.

Her yeni projede kendimi geliştirmeyi, daha işlevsel ve kullanıcı dostu web siteleri oluşturmayı hedefliyorum.
